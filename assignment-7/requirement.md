# Assignment 7: Requirements

Project: Student Homework Checklist

## 1. Description
Students need a simple way to keep track of homework tasks from their different classes and see which tasks are finished. The system should let students add tasks, see each task's status, mark tasks as completed, and delete tasks.

## 2. Requirements List
- R1: Users shall be able to add a homework task by entering its name.
- R2: Users shall be able to see their tasks and whether each task is completed.
- R3: Users shall be able to mark a task as completed.
- R4: Users shall be able to delete a task.
- R5: The system shall prevent users from adding an empty task.
- R6: The system shall be usable on a phone-sized screen without horizontal scrolling.
- R7: Users shall be able to operate the task controls using a keyboard only.
