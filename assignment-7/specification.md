# Assignment 7: Specification

Project: Student Homework Checklist

## 1. Description
The system will be a simple webpage with a homework checklist. It will have a text input, an Add button, and a list of tasks. Each task will have controls to mark it as completed or delete it.

## 2. Specifications List
- S1 (for R1): When the user enters a task name and clicks Add, the system adds the task to the list.
- S2 (for R2): Each task in the list shows whether it is completed or not completed.
- S3 (for R3): When the user clicks the task's Complete control, the task is shown as completed.
- S4 (for R4): When the user clicks the task's Delete control, the task is removed from the list.
- S5 (for R5): When the input is empty, the system adds no task and shows a message asking the user to enter a task.
- S6 (for R6): The page layout fits a phone-sized screen with no horizontal scrolling.
- S7 (for R7): All task controls are standard inputs and buttons that can be reached with Tab and activated with Enter or Space.
