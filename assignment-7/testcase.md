# Assignment 7: Test Cases

Project: Student Homework Checklist

## 1. Description
The system will be tested to check that students can add, complete, and delete homework tasks. Testing will also check empty input, phone-sized screens, and keyboard-only use.

## 2. Testing List
- T1 (for S1): Enter a task name and click Add. Expected: the task appears in the list.
- T2 (for S2): Add a task. Expected: the list shows the task and that it is not completed.
- T3 (for S3): Click Complete on a task. Expected: the task shows as completed.
- T4 (for S4): Click Delete on a task. Expected: the task is no longer in the list.
- T5 (for S5): Click Add with the input empty. Expected: no task is added, and a message asks the user to enter a task.
- T6 (for S6): Open the page on a phone-sized screen. Expected: all controls are usable with no horizontal scrolling.
- T7 (for S7): Using only the keyboard, add, complete, and delete a task. Expected: every action works without a mouse.
